# XSGrok - AI小说生成器

基于 Grok 4.20 Beta API 的 Android 小说生成应用。

## 功能特性

- 🎭 **多模型支持** - 4种Grok模型适配不同创作场景
- 📝 **流式生成** - 实时显示AI创作内容
- 📚 **小说管理** - 创建、编辑、导出完整小说
- 👤 **角色管理** - AI记住角色设定
- 🌙 **深色模式** - 护眼创作体验
- 📱 **自适应** - 手机/平板完美适配

## 支持的模型

- `grok-4.20-beta` - 日常创作
- `grok-4.20-beta-0309-reasoning` - 复杂推理
- `grok-4.20-beta-0309-non-reasoning` - 快速生成
- `grok-4.20-multi-agent-beta-0309` - 多智能体深度创作
